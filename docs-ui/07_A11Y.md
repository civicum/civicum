# 07 — Accesibilidad (A11Y)

**Propósito:** Define los estándares de accesibilidad que toda pantalla y componente de CIVICUM debe cumplir. El objetivo es WCAG 2.1 AA como mínimo, con aspiración a AAA en componentes críticos. Incluye reglas de contraste, navegación por teclado, ARIA, y respeto por preferencias de movimiento.

## Decisiones que debe contener

- [ ] Nivel de conformidad: WCAG 2.1 AA obligatorio, AAA aspiracional
- [ ] Contraste: ratios mínimos (4.5:1 texto normal, 3:1 texto grande y UI)
- [ ] Navegación por teclado: focus-visible, tab order, skip links
- [ ] ARIA: roles, labels, live regions, landmarks obligatorios
- [ ] Motion: `prefers-reduced-motion` — qué animaciones se desactivan
- [ ] Texto: tamaño mínimo, zoom 200%, texto alternativo para imágenes
- [ ] Formularios: labels asociados, error announcements, autofill
- [ ] Testing: herramientas (jest-axe, axe-core, Lighthouse) y umbrales

## Evidencia exigida en Gate 4

> Toda regla debe tener test automatizado (`jest-axe` o Lighthouse CI). 0 violations bloqueantes. DOCREF a `docs/testing/audit-accesibilidad.md`.
